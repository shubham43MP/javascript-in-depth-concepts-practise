❌ Hoisting = JavaScript moves declarations to the top.

✅ Hoisting = bindings/declarations are established
   as part of scope/environment instantiation before
   normal statement execution.

| Declaration        | Binding created before execution? | Initial state       |
| ------------------ | --------------------------------: | ------------------- |
| `var x`            |                               Yes | `undefined`         |
| `let x`            |                               Yes | uninitialized / TDZ |
| `const x`          |                               Yes | uninitialized / TDZ |
| `function foo(){}` |                               Yes | function object     |
| `class Foo {}`     |                               Yes | uninitialized / TDZ |


```
Hoisting describes the behavior resulting from declarations being instantiated in their scope before normal statement execution begins. Different declarations have different initialization semantics: var is initialized to undefined, function declarations are initialized with their function objects, while let, const, and class bindings remain uninitialized until their declarations are evaluated, producing the Temporal Dead Zone.
```
