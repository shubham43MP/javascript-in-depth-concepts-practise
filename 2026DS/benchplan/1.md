What happens internally when JavaScript executes a function?

Basically explain a function execution rtight from the global scope till return and pop from executiuon context

Function called
    ↓
Create Function Execution Context
    ↓
Set up parameters / local variables
    ↓
Establish lexical scope / outer environment
    ↓
Determine `this`
    ↓
Push context onto Call Stack
    ↓
Execute function body
    ↓
Return value
    ↓
Pop context from Call Stack

When a JavaScript function is invoked, the engine creates a new function execution context. It contains the function's parameters, local variable bindings, lexical environment, reference to its outer scope, and its this binding. That execution context is pushed onto the call stack. The function body then executes, resolving variables through its lexical environment and scope chain. Once the function returns, its execution context is popped from the stack. Every invocation gets its own execution context, which is why recursion and closures can maintain separate state.”
