12. What happens when `new Foo()` executes?

```
When new Foo() executes, JavaScript creates a new ordinary object, sets its internal [[Prototype]] to Foo.prototype, invokes Foo with that new object as this, and then handles the constructor's return value. If the constructor explicitly returns an object or function, that value becomes the result; otherwise primitives are ignored and the newly created object is returned. That's also why instances can access methods defined on Foo.prototype, and why instanceof generally works by finding Foo.prototype in the object's prototype chain.”
```
